# Documentos de venta y entrega

Plantillas para cada cliente. Copie el archivo, reemplace lo que está entre `[CORCHETES]` y guárdelo **fuera del repositorio** o en `negocios/privado/` (nunca publique documentos de clientes reales).

| Momento | Documento |
|---|---|
| Primer contacto y arranque | `checklist-onboarding.md` |
| Desarrollo a la medida | `diagnostico-a-la-medida.md` |
| Cotizar | `propuesta.md` |
| Cobrar (50% y 50%) | `cuenta-de-cobro.md` |
| Antes de tocar datos de clientes del negocio | `acuerdo-encargo-datos.md` |
| Al terminar | `documento-de-entrega.md` |
| Cada mes (plan de mantenimiento) | `registro-mantenimiento.md` · `informe-mensual.md` |

La guía de vendedoras y las hojas de planes impresas ya existen y no se repiten aquí. Para exportar a PDF: abra el `.md` en un editor que lo muestre (VS Code, Typora, Google Docs al pegarlo) e imprima a PDF.
