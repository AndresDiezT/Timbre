## 4. Respuestas rápidas

Herramientas para la empresa → Respuestas rápidas → Agregar. Se usan escribiendo «/» en el chat.

**/bizcochos**

```
Media plancha US$45 · Plancha US$80. Sabores: vainilla, chocolate y guayaba. Encargos con tres días de anticipación.
```

**/encargo**

```
Para separar su encargo necesitamos: fecha, sabor, número de porciones y el nombre que lleva. Se separa con el 50%.
```

**/pago**

```
Puede pagar por ATH Móvil, tarjeta o en efectivo al recoger.
```

**/entrega**

```
Entregamos en San Juan, Carolina y Guaynabo desde US$10. ¿A qué zona sería?
```

**/listo**

```
Su pedido ya está listo para recoger. ¡Lo esperamos!
```

**/gracias**

```
Gracias por su compra. Si le gustó, nos ayuda muchísimo con una reseña en Google.
```

> La app no responde sola a opciones numeradas (por ejemplo «escriba 1 para precios»). No ponga menús así en los mensajes automáticos.
