## 4. Respuestas rápidas

Herramientas para la empresa → Respuestas rápidas → Agregar. Se usan escribiendo «/» en el chat.

**/menu**

```
Pollo entero $42.000 · Medio pollo $24.000 · Picada para dos $48.000 · Hamburguesa $22.000. El menú completo está en el catálogo.
```

**/domicilio**

```
Con gusto. Envíenos su dirección completa, el pedido y si paga en efectivo o transferencia. El domicilio vale $4.000.
```

**/pago**

```
Recibimos efectivo, Nequi, Daviplata, Bre-B y datáfono.
```

**/encamino**

```
Su pedido ya va en camino. Llega en unos 20 minutos.
```

**/reserva**

```
Listo, su mesa quedó apartada. Si se le hace tarde, avísenos por aquí.
```

**/gracias**

```
Gracias por su pedido. Si le gustó, nos ayuda mucho con una reseña en Google.
```

**/confirmar**

```
Recibimos su pedido. Llega en unos 40 minutos. ¡Gracias por pedir directo!
```

> La app no responde sola a opciones numeradas (por ejemplo «escriba 1 para precios»). No ponga menús así en los mensajes automáticos.
